# 分镜与成套检查

少量图用短列表，批量图用表。每项记录：编号、使用情境、情绪、主体动作、文字原文/无字、布局、背景、输出要求。漫画另写每格的说话者、动作与信息变化。

两格示例：同一轮式机器人第一格昂首宣布“我准备好了”，第二格面对巨大纸箱沉默；落点靠体积差和姿态变化，不能突然长腿逃跑。安慰贴纸则只需双臂递出小毯子，柔和目光，无须追加失败或反转。

将“开心”落实为眼睛、嘴形、躯干朝向与动作；物种没有某部位时用其可用结构表演，例如机器人面罩图形、天线角度与机械臂姿势。不能给角色没有的嘴巴强行画嘴角。

漫画检查：

- 每格是否新增有效信息，删掉一格是否仍完全相同；按叙事精简。
- 人物身份和空间关系是否连续，左右变化是否有明确转场。
- 精确文案是否逐字正确，气泡尾巴是否指向说话者，阅读方向是否符合语言与要求。
- 原话、内心活动、旁白和创作改写是否混淆。

成套检查：

- 遮住文案后，各张情绪和动作是否仍有差别。
- 同一母版的颜色、标志、结构是否一致；夸张能否仍识别角色。
- 缩小到使用尺寸后脸与动作是否清楚，边缘是否留足空间。
- 独立文件是否齐全，透明/尺寸/格式哪些已实测，哪些仍未验证。

修正先处理身份或信息错误，再处理装饰；不要为统一性把所有动作改成同一个姿势。检查结果写具体问题，不用总评分掩盖缺字、错角色或缺文件。
