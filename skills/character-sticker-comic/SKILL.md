# 通用角色表情包与漫画

从角色卡、参考图、文字故事或截图提炼可见动作和情绪。角色可以是人、动物、机器人或吉祥物，不带入鲸鱼娘身份、固定性格和反转套路。

## 接续角色与范围

沿用已确认母版、角色卡、数量、语言及用途；参考图按身份/画风/动作/构图区分。没有母版时，根据足够明确的文字先做一张代表性样图；需要完整视觉人设时用 `character-image-design`，不为每次表情包重做设定。

用户明确要求出图就是当前范围的生成授权；仅要创意时不调用图像工具。缺少数量时单张请求做一张，“一套”默认六张并先简述所选情绪；已有明确张数不擅自扩充。若身份本身尚未解决，先完成代表样图，再沿用它扩展剩余数量，不把内部样图额外计为用户要求的数量。

普通贴纸不强制搞笑，安慰可以温和、拒绝可以坚定。配文以用户原文为准，默认沿用当前对话语言；不读取历史会话推断语言。

## 编排内容

按 [分镜与成套检查](references/story-plan.md) 给每张图确定用途、动作、表情、文字和布局。

- 表情贴纸：一个清楚情绪和一个主要动作；小尺寸仍能认出角色与情绪。
- 梗图：一个可理解的情境和落点；需要文字时保证画面与文案互相补充。
- 漫画：按叙事需要选择单格、双格或四格等布局；不为了配额加空格或强制反转。保持阅读顺序、人物站位和对话归属。
- 成套：各张表达不同意图，避免仅更换标签或重复相同姿势。表演强弱按角色与情境决定，不固定比例。

引用截图/聊天时区分原话与创作改编，保留关键事实和说话者；截图可只作语义来源，不默认复制用户名、界面和其他无关内容。准确文字单独列出，未要求文字时允许无字。

## 出图与纠正

提示词顺序：固定角色身份 → 本张情绪/动作或分镜 → 每格人物位置与动作 → 精确文字与归属 → 画风/构图 → 背景及输出规格。

1. 以同一认可母版维持身份，每张重复必要锚点；换动作不能改变物种结构，换画风不能改变身份配饰。参考图片只负责声明的维度。
2. 实际生成使用当前图像工具，有 `imagegen` 技能时按需读取；编辑本地参考前先查看图像。不得使用鲸鱼娘专用脚本假装任意角色适配已完成。
3. 每张贴纸交付独立图像；若用户要图集才生成图集。预览拼图不能替代独立文件。透明贴纸要求真实 alpha，不接受画出的棋盘格；不要未验证就承诺具体格式、尺寸或透明通道。
4. 检查身份、结构、情绪可读性、文字逐字准确、气泡归属和阅读顺序。多图再检查重复创意与角色漂移；不凭缩略图就宣称细字准确。
5. 只修正失败图，保留合格图。每张默认最多两轮定向修正，用户预算优先；相同问题反复出现或工具不可用时说明剩余缺陷，不自动切换付费服务或无限重试。

## 交付

展示独立成品及简短情绪/用途清单；必要时附整套预览，清楚区分成品、候选和待修。连续创作保留母版、角色锚点及精确文案，不强制多阶段清单和目录。

QQ 上传、收藏、备注和发送仅在用户明确要求时使用 `qq-sticker-pack`；生成图像不自动授权对外发送。游戏平台素材/控件实现另走平台技能。本技能无额外运行依赖；图像工具不可用时只能交付方案并明确未出图。
