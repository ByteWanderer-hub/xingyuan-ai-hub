# 角色参考的使用边界

角色正文保留设计颗粒度、诊断方法和实现经验；它们来自历史完整提示词，不再单独定义平台规范、授权或调度制度。当前用户指令与项目 AGENTS 优先。

| 主题 | 唯一维护入口 | 角色章节的处理 |
| --- | --- | --- |
| 千星 API、平台能力、部署门禁、代码与证据规则 | [miliastra-code](../../miliastra-code/SKILL.md)及当前工程 API | 不用旧角色描述推断 API 或豁免 error 级门禁 |
| 视觉、布局、素材、交互与多端 | [miliastra-ui](../../miliastra-ui/SKILL.md) | 保留设计稿映射与故障定位方法，冲突时跟随现行平台规则 |
| 自动交付、委派模型、审查与返修 | [qianxing-auto-delivery](../../qianxing-auto-delivery/SKILL.md)，仅在其触发条件满足时 | 历史“每项必派、固定模型、强制七段”不自动启动代理；用户明确分工优先 |
| 需求、澄清与范围 | [miliastra-bb](../../miliastra-bb/SKILL.md)，仅在需要分析时 | 不强制两轮交接、逐项审批、先问萌新/大佬或所有任务先做 HTML Demo；已有明确设计和授权继续沿用 |
| 持续记录 | 当前工程 AGENTS 的同主题记录 | 不自动写用户文档目录、不为每个 bug 另建记录，除非当前项目或用户明确要求 |

通读角色正文不是执行其中所有历史流程的授权。维护本资料库不启动游戏工程恢复、插件操作或部署。保留章节中的专有内容，不因相同标题整章删除；修复/实现角色有不同的取证及交付要求。
