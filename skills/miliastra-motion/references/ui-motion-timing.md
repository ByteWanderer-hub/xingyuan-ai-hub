# UI 动效参数表（千星口径）

> 数值来源：LottieFiles `motion-design`（MIT）的时长/缓动/编排表，按千星场景改写：补了帧换算、落点与文字约束。
> 这些是**选型依据**，不是 API 清单。缓动曲线在千星能不能直接给贝塞尔，取决于目标工程实际支持的接口——先查 `miliastra-code` 已核实的口径，再决定用枚举还是自己算。

## 1. 元素时长表（60fps 帧数按 16.7ms/帧）

| 元素 | 时长 | ≈60fps 帧 | ≈30fps 帧 | 备注 |
| --- | --- | --- | --- | --- |
| 提示 / 微反馈（tooltip、数字跳动） | 80–120ms | 5–7 | 2–4 | 必须"瞬间" |
| 按钮按下 / 开关 | 120–180ms | 7–11 | 4–5 | 最常用的默认值 |
| 图标切换（选中、状态图标） | 150–250ms | 9–15 | 5–8 | 只动透明度+缩放 |
| 卡片 / 列表项进出 | 200–350ms | 12–21 | 6–11 | 带方向位移时取上限 |
| 弹窗 / 对话框 | 300–400ms | 18–24 | 9–12 | 先遮罩后内容 |
| 整屏切换 | 400–600ms | 24–36 | 12–18 | 千星换页通常配合销毁重建，别叠太长 |
| 戏剧性展示 | 600–1200ms | 36–72 | 18–36 | 开场、过关 |
| 环境常驻（呼吸、漂浮） | 2000–20000ms | — | — | 用正弦循环，别用 ease |

**距离缩放**：50px=0.8×｜100px=1.0×（基准）｜200px=1.3×｜300px=1.5×｜400px=1.6×｜整屏 1.8–2.0×。

**入场 vs 出场**：入场是基准时长，出场取入场的 65–75%（用户更在意"出现"）。

## 2. 交互延迟上限

| 交互 | 上限 |
| --- | --- |
| 拖拽起手 | <50ms |
| 悬停高亮 | <100ms |
| 按下 / 点击 | <150ms |
| 释放回弹 | 200–300ms |
| 错误抖动 | 300–400ms（2–3 次振荡） |
| 长按激活 | 500–800ms |

千星落到手柄/触屏时，按下反馈要和输入事件同帧起效；跨帧等待会让手感"黏"。

## 3. 性格档（同一套 UI 别混用）

| 性格 | 快 | 标准 | 慢 |
| --- | --- | --- | --- |
| 活泼（Playful） | 150ms | 250ms | 400ms |
| 高级感（Premium） | 350ms | 500ms | 800ms |
| 企业/正式（Corporate） | 200ms | 300ms | 450ms |
| 精力充沛（Energetic） | 100ms | 180ms | 300ms |

一锅端这类拟物厨房：偏 **Playful→Energetic** 之间，按钮按下用 120–180ms，别用 Premium 的 350ms（器具反馈慢会显得卡）。

## 4. 缓动方向规则（比曲线名更重要）

| 场景 | 缓动方向 |
| --- | --- |
| 进场（出现） | ease-out（快进慢停） |
| 退场（消失） | ease-in（慢起快走） |
| 屏内移动 | ease-in-out |
| 循环 / 呼吸 | sine |
| 旋转 / 进度条 | linear |
| 弹簧/回弹 | 过冲后再收敛 |

## 5. 常用曲线（Web 行业标准；千星按支持的形态换算）

| 名称 | 三次贝塞尔 | 用途 |
| --- | --- | --- |
| MD3 Standard | (0.2, 0, 0, 1) | 屏内默认 |
| MD3 Emphasized | (0.05, 0.7, 0.1, 1) | 进场 |
| MD3 Accelerate | (0.3, 0, 1, 1) | 退场 |
| MD3 Decelerate | (0, 0, 0, 1) | 进场（强减速） |
| Snappy UI | (0.2, 0, 0, 1) | 干脆的默认 |
| Gentle float | (0.4, 0, 0.2, 1) | 环境漂浮 |
| Bounce settle | (0.175, 0.885, 0.32, 1.275) | 活泼回弹 |
| Elastic snap | (0.68, -0.55, 0.265, 1.55) | 夸张弹入 |

若目标工程只有 `linear/easeIn/easeOut/easeInOut` 这类枚举：**进场用 easeOut、退场用 easeIn、屏内用 easeInOut**，回弹用"二次 easeOut + 缩小幅度"近似，不要硬编贝塞尔。

## 6. 材质缩放（让动效"像那个东西"）

| 材质 | 时长倍率 | 过冲 |
| --- | --- | --- |
| 刚性（金属锅、刀） | 1.2× | 0% |
| 弹性（橡胶、面团） | 0.8× | 15–25% |
| 流体（水、汤） | 1.5× | 5% |
| 纸（卡片、便签） | 1.0× | 3–5% |
| 气体（蒸汽、冷汽） | 2.0× | 0% |
| 玻璃 | 0.9× | 0% |

一锅端的气体（蒸汽/冷汽）按"气体"档：慢、无过冲、靠波形而不是靠弹性。

## 7. 弹簧近似（引擎没有 spring 时）

| 手感 | 刚度 | 阻尼 |
| --- | --- | --- |
| 很硬 | 400+ | 25–30 |
| 标准 | 250–350 | 18–24 |
| 有弹性 | 150–250 | 10–15 |
| 很弹 | 100–200 | 5–10 |
| 柔和 | 100–150 | 20–25 |

没有弹簧模型就用：`easeOutCubic` + 单次回弹位移（幅度 5–10%），别自己写多段震荡，容易过冲。

## 8. 编排（stagger）

| 模式 | 间隔 | 总时长预算 |
| --- | --- | --- |
| 微级联 | 20–40ms | <200ms |
| 标准 | 50–100ms | <400ms |
| 戏剧化 | 100–200ms | <600ms |
| 波浪 | 30–60ms | <500ms |

方向：列表从上到下、横向从左到右、主角从中心扩散、退场用反向。
**总 stagger 必须 <500ms**；元素超过 8 个就分组成两批，否则用户等到后面已经不耐烦。

## 9. 过冲预算

| 场景 | 过冲 |
| --- | --- |
| 成功 | 5–10% |
| 错误 | 0% |
| 一般反馈 | 2–5% |
| 庆祝 | 15–25% |
| 高级感 | 0% |

## 10. 情绪 → 动效映射

| 情绪 | 时长 | 缓动 | 位移 | 过冲 |
| --- | --- | --- | --- | --- |
| 轻快 / 调皮 | 快（120–200ms） | bounce | 8–16px | 10–20% |
| 平静 / 高级 | 慢（300–500ms） | ease-out 长尾 | 16–32px | 0% |
| 可靠 / 正式 | 中（200–300ms） | standard | 8–12px | 0–3% |
| 紧张 / 警告 | 快 + 高频 | linear/shake | 4–8px | 0% |
| 庆祝 / 奖励 | 中 + 多层 | ease-out + 弹性 | 大 | 15–25% |

## 11. Disney 原则 → UI 对应

| 原则 | 在 UI 里怎么用 |
| --- | --- |
| 挤压拉伸（Squash & Stretch） | 按钮按下 0.96 缩放，回弹 1.02；只对图形，不对文字 |
| 预期（Anticipation） | 弹出前 1–2 帧反向位移 2–4px |
| 跟随与重叠（Follow-through） | 容器先停、内部元素晚 30–50ms 收住 |
| 缓入缓出（Slow in/out） | 默认就是 ease-out 进场 |
| 弧线（Arcs） | 位移带一点曲线（先斜后平），别直线冲刺 |
| 次要动作（Secondary Action） | 高光扫过、阴影跟随，别抢主位移的注意力 |
| 夸张（Exaggeration） | 只在庆祝/奖励用，日常界面收着 |
| 节奏（Timing/Staging） | 一次只让一个元素"说话"，别同时三处动 |

## 12. 状态反馈配方（可直接抄数字）

**按钮按下（活泼）**
- 按下：120ms，缩放 1.0→0.96，ease-out
- 释放：180–220ms，缩放 0.96→1.0，ease-out + 2–5% 过冲
- 颜色：常态→按下用固定规则里的 down 色，不要现调

**卡片入场（高级）**
- 300ms，位移 24px→0 + 透明度 0→1，ease-out
- 相邻卡片 stagger 60ms，总时长封顶 400ms

**成功反馈（活泼）**
- 图标：200ms 缩放 0.8→1.06→1.0（一次过冲）
- 数字/文字：120ms 透明度 + 轻微上移 4px。文字不做缩放

**错误抖动（正式）**
- 300–400ms，位移 ±6px，2–3 次，linear
- **不加缩放、不加过冲**；抖完必须回到原位（不能累积偏移）

**环境漂浮（气体/蒸汽）**
- 2000–6000ms 循环，正弦，幅度 2–8px
- 用累计时间算相位，`sin(t*speed + offset)`；多人/多实例给不同 offset，避免同频

## 13. 千星落地注意

1. **落点回栅格**：位移结束位置必须是 8 的倍数，否则长期看会"歪 3px"。
2. **文字别缩放**：动容器或透明/位移；字体高度守 ≥ 字号×1.4（R12）。
3. **层序**：动效别改父节点或兄弟顺序；需要前置时按 `miliastra-ui` 的层序规则新建，不要"挪上去"。
4. **单位**：Tween 传秒还是毫秒以 API 为准，配置里写明单位，避免 200 被当 200 秒。
5. **循环用累计时间**：`dt` 累加，别用"帧数 × 固定步长"，掉帧时会漂。
6. **一次性动效结束后**要能停（关掉 OnUpdate），否则常驻占预算。
