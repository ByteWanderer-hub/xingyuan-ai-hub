# 有状态场景动效：预览、几何与编排

用于门、气体、食物达成、融化、结算和切关等联动动效。来源为《天堂之门》迭代反馈的工程归纳；下面的玩法例子不是其他地图的默认规则，也不代表某一实现已经通过真机验收。API 和部署仍由 `miliastra-code` 负责。

## 先冻结行为，再设计运动

给每类交互记录：前置状态 → 接受/拒绝事件 → 视觉阶段 → 权威后置状态 → 中断恢复。动画消费玩法事件和前后快照，不靠“看起来门开了”反推房间连通，不用动画完成回调重新计算并重复提交整次玩法结果。

- 区分门自身开关、房间连通、气体转移、湮灭和口袋切换。同样是开门，结果可能不同；双门组合需要覆盖 00/01/10/11 及两个操作顺序。视觉未变的状态也可能发生有效转移，不能只比较气体类型字符串来决定有没有动画。
- 项目案例曾约定“转移后快速关门，湮灭后保持开门”；这应来自该项目事件契约，不写成平台规则。关闭时机、时长与被点击的门/同组门分别定义，不能批量关闭所有连通门。
- 不可操作的门也要有短反馈，但拒绝动作不能改变玩法。输入锁定、撤销和重来使用同一权威状态，不由可见性单独决定资格。
- 中断时明确提交或回滚哪一份状态，取消旧动效并恢复层级、透明度、可交互性。旧完成回调不能影响新一局；具体生命周期见 [UI 交互可靠性](../../miliastra-code/references/ui-interaction-reliability.md)。

## 气体：固定本体与有界边缘

先把用户圈选转成三个独立定义：固定本体区域、允许波动的边带、禁止覆盖的区域。内圈/外圈是约束，不是要在成品里画出的描边。固定本体不随时间整体缩放或周期变透明；波动只在允许边带内，颜色和本体透明度沿用定稿。

1. 从房间与开门通道的几何并集生成轮廓；口袋、墙和未连通区域按当前状态排除。不要给每个房间各画一个大矩形后靠重叠透明度“连起来”。
2. 若采用连续轮廓，沿闭合边界的弧长传播相位，处理四角与首尾接缝；独立椭圆一排排呼吸往往形成明显鼓包，不能冒充连续边缘。振幅、周期与空间波长分别定义，不能只加快频率掩盖接缝。
3. 检查全周期的最大外扩和内缩，包括拐角、狭窄通道、凹口与裁切端点；不只检查若干中心采样值。关闭整条跨界条带可能留下缺口，局部裁切必须核对实际轮廓。
4. 选择原生可用资产/控件实现，遵守 [同型资产优先](../../miliastra-ui/SKILL.md)。没有匹配的动态形状时，明确平台能力缺口，先做小样验证；不把成百上千细条当成默认兜底。近似误差、透明拼接缝、叠色和控件成本分别验收，数学误差小不等于渲染无缝。
5. 首帧就使用当前颜色和透明度；复用对象时重置缓存。隐藏边缘要退出活跃更新，单纯隐藏控件不等于停止脚本计算。

## 转移与湮灭：有方向的阶段

- 源区域按到出口的路径距离排序，先碎片化远端，再处理靠门区域；不要用世界坐标左到右冒充通用方向。
- 保持定稿碎片尺寸及整体本体几何，按批次消隐/位移收拢；“向门收缩”不必等于把整张图片宽高缩小。目标按入口向内部逐步碎片填充；源、通道、目标阶段是否重叠按预览定稿。
- 多连通房间按连通区域处理，开着的门洞也在气体覆盖范围内。粒子路径和自身半宽都要避墙，端点可达不证明路径不穿墙。
- 湮灭明确接触面与推进方向，写出在每个房间里哪个边先消失。可用首帧、前四分之一、后四分之一、结束帧检查方向，避免只看最后归零。
- 移动中与稳态使用同一覆盖/遮挡规则，避免切换瞬间重复叠色、通道断层或残留条带。

## 门、食物与结算

- 门扇、铰链、落点阴影和热区来自同一个旋转模型，普通门与口袋门复用动画入口；双门不能只修改逻辑开关而直接跳终态。墙边的门旋转不意味着要挖掉外墙或把气体泄到场景外。
- 开向提示与真实转轴一致，按目标显示尺寸检查辨识度。描边箭头可先画所有浅色底线，再画深色前景，避免逐段底线盖住上一段造成虚线/发糊；后续局部删除提示只作用于指定实例。
- “气体在最上层”应落实为语义层级：气体高于普通场景，反馈/模态层另有优先级。食物满足条件需突出时，先提升到气体上方再播放；失去资格、撤销、重来时恢复原层级。不要每帧无条件置顶。
- 融化的结束帧显式隐藏缩小的球体及属于它的装饰，不能留下几像素残影。杯子、球体、融化物、结果插图分别有所有权；失败只要空盘时，不再生成旧杯子子树。
- 达成后先播已确认的结算反馈，再显示胜利叠层；计分/结算恰好一次。下一关使用“遮盖完成 → 新关构建就绪 → 揭开”，不能按固定帧数假定构建完成。具体输入阻挡和取消见工程参考。

## 预览交付与验收

用户要求先看时，先交能实际播放的预览，批准范围明确到组件/阶段；批准 GIF 不自动等于授权部署。浏览器和原生实现共享配方、关键帧和版本；浏览器使用平台不支持的变换时，标明拟采用的近似与差异，不宣称效果完全相同。

手机访问不了本机 `127.0.0.1` 时，不把本机 HTTP 200 当作手机可看。用户改要 GIF，就交实际 GIF 文件，含足够循环、清楚的缩放和起止停留；不只再给同一个网页链接。通过定稿后冻结参数，后续修改使用字段/实例白名单。

验证挑受影响场景：普通/口袋门、横纵方向、狭长/凹形/多连通区域、气体重叠边界、撤销重开、模态期间输入。除了代码数值，查看完整上下文的合成画面与连续播放。原生控件成本先按 [性能适配](../../performance-optimization/references/miliastra.md) 小样测量；预览通过、逻辑通过、原生渲染通过和真机性能通过分开记录。
