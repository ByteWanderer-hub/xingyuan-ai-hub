# 素材检索与接入

属于 miliastra-ui。仅在需要查找千星素材或核对资产时读取；UI 排版和普通代码修改不必加载。不预读项目交接、源码、全部资产目录或历史搜索记录。

## 目标与授权

从上下文提取用途、资产类型和已有风格，例如面板底板、关闭图标、轻柔点击声、纸面解谜配乐或蓝色扩散特效。无需为简单搜索重新做需求访谈。用户只要求找素材时交付候选；要求接入时，再按工作区 AGENTS 和 miliastra-code 核对工程及当前 API。不将某个项目的关卡号、模板号或部署路径当作默认值。

## 图片与图标

- 已提供 ID 对照图/本地静态资产 ZIP 时，先走 [资产包映射与只读查询](static-image-pack.md)，复用可核实图源，不重复联网检索；分类/描述先筛选，具体外观与元数据再核对。缺少该包时才使用下面的已有目录入口。
- 优先复用已有、适配且核实过的官方图形素材；按用途、形状与风格找少量候选，避免用大量微小色块重绘现成美术。仅调现有控件位置时不重复检索。
- 发现可用的 `miliastra_asset` 工具，按当前 schema 用 `op=catalog` 查询分类或已知 ID，设置小 `limit`；只需数量与分类时用 `summaryOnly:true`。需要分类元信息时才开 `withMeta`。
- 目录分类包括底板、装饰图案、功能/玩法图标、分隔线等，以本次返回为准。不要把分类名当成单图名称，也不要假定 `catalog` 支持关键词名称搜索。
- `op=icon-search, q=用途` 用于语义检索图标，已知 ID 可按工具 schema 查单条。
- 本地文字标注在 [图片资产索引](../../miliastra-code/assets/asset-catalog.md)，先用 `rg -n -m 10 <短关键词> <索引路径>` 定向定位。仅当 `<miliastra-code>/assets/Image_sample_by_id.json` 存在时使用 `node <miliastra-code>/scripts/search-assets.mjs <关键词>`；移机后缺少该依赖则继续用 Markdown 索引或目录接口，不重复运行报错脚本。普通搜索不用 `--catalog` 重写索引，不整读或遍历全目录。
- 查官方美术时不要开启 `simOnly:true`：它会把目录限制为少量模拟器支持的基础几何，漏掉底板与图标。模拟器不能画出某张素材时保留候选并标注真机待验，不因此改回像素拼图。
- 项目控件模板另查当前关卡的 `clientui` 索引，先摘要再定位目标子树。平台图片 ID 与项目模板索引分别记录，不能互换；目录存在不代表已在项目导入。
- 核对回执的来源、缺图项及未验证说明。当前目录可由第三方镜像提供，镜像不是官方服务端点，不能保证与正式服最新版本一致；`imgExists` 也不代表真机可加载。
- 候选先确认类型和接入条件，再比较形状/用途、风格、比例、清晰度及状态支持。图片没有名称时用“分类 + ID + 外观描述”，不虚构官方名称。仅有文字标注时明确未做视觉确认；视觉验收由用户确认，不生成图片。

## 音效、背景音乐与特效

- AI 搜索库：<https://tool.xiaomol444.xyz/AISearch>，适合用中文描述音效、特效、背景音乐。图片/图标优先走上述目录和标注，不假定网站支持未列出的类型。
- 从搜索结果实际给出的详情链接进入 BgmPlayer、SoundEffectPlayer 或 EffectPlayer，不自行拼接详情地址。
- 用浏览器访问，默认后台打开；普通网页读取不可用时改用浏览器，先查看实时状态再定位搜索和筛选，不沿用旧会话元素编号。
- 搜索仅包含选材所需描述，不提交源码、存档、日志、凭据或无关对话。网站有额度与等待状态，先发一条聚焦请求，已有候选优先筛选，确有缺项才补查；不全站爬取或批量下载。
- `miliastra_asset op=sound-search, q=关键词, limit=少量` 可查音效名称；按当前 schema 核对语法（当前空格表示 AND，不支持拼音或首字母），无结果时改短词。
- `op=sound-get, id=已获得的ID` 核对名称、分类、时长；音效目录查不到 BGM 或特效不代表资源不存在，应回到对应类型详情页核对。
- 连续点击宜短，成功反馈需易区分，配乐需适合持续游玩；每个交互不必使用不同资产。网站 AI 的建议仅作候选理由，以资源说明和可获得的试听为准。
- 试听可用时检查截断、循环尾部、余响；仅能读说明时明确未试听，播放状态成功不等于已确认听感。

## 候选核对与缺口

记录用途、类型、名称（若有）、ID、来源、选择理由和核实程度；相关尺寸、颜色、时长等字段缺失时标明未提供。图片 ID、控件模板索引、音效 ID、BGM 网站资产 ID 和节点图配置索引不能按数字长度互换。

来源不可用时说明具体入口，使用当前可用的其他来源；无可核实结果就保留待选，不编造 ID。图形素材缺口可用少量基础图形临时占位并标明待接入，不把占位细化成像素拼图。

## 需要接入时

先确认目标项目及当前 API，只实现已授权的接入。以下是已有资料中的接口与配置区分，实际使用前核对当前文档：

- 图片/模板沿用主技能的层序、素材组整体缩放和交互契约；不混淆图片与模板参数，不默认镜像中的素材在真机可显示。
- 客户端音效：`game.PlayAudio2D(audioId)` 返回实例 ID，`game.StopAudio(instanceId)` 停止，`game.IsAudioAlive(instanceId)` 查存活。已知文档没有音量/音高参数，不自行添加。
- BGM 独立配置：编辑器「背景音乐管理」可选音乐及音量、片段、循环、间隔、速度、淡入淡出，服务端也有相关 BGM 节点。不能将网站 BGM 资产 ID 填进音效接口或直接当作节点图“背景音乐索引”。
- 音效按有效动作或状态变化触发，避免每帧重播、无效按钮发声和同类叠加；实例随玩法生命周期清理，音频失败记录原因但不中断主玩法。
- 需要作者配置时，给出具体名称、ID 和操作步骤，明确待操作项；未配置不能声称已接入。

纯搜索无需跑玩法测试；改代码按工程规则备份、验证并显式指定部署目标。分别报告“已找到”“目录已核实”“已写入脚本”“编辑器已配置”“真机效果已确认”，模拟器成功不能代替真机或用户的听觉/视觉验收。
