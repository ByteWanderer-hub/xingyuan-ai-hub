# 角色卡与检查表

只填与本次任务有关的内容。用户已确认的信息优先，不把助手推测写成定案。

| 字段 | 记录内容 |
| --- | --- |
| 名称与用途 | 角色称呼、头像/立绘/设定/插画等用途 |
| 固定身份 | 物种、轮廓、脸型、眼睛、毛发/皮肤/外壳、关键颜色与标志；选 3–6 个最有辨识度的锚点 |
| 结构 | 肢体/翅膀/尾巴的数量及连接方式、体型；比例仅在已有要求时固定 |
| 性格表现 | 与本画面有关的态度及可见表演；不把角色性格当刻板剧情模板 |
| 允许变化 | 服装、表情、姿势、画风、光线、场景；用户锁定的项目移入固定项 |
| 参考图分工 | 文件/图片标识 → 身份/画风/姿势/服装/构图；主身份母版唯一且明确 |
| 未定项 | 未见背面、遮挡配件、用户未定颜色等，标为本次设计建议 |
| 本次要求 | 张数、视图、精确文字或无字、比例/尺寸、背景、平台 |

示例：圆形奶油色小机器人，单块深蓝面罩、左侧一个橙色天线、两只短机械臂、轮式底盘；固定轮廓和配色，允许服装及场景变化。不能因采用人类姿势参考而加出双腿，也不能因更换水彩画风丢失天线。

检查顺序：身份锚点是否保留 → 结构能否成立 → 本次动作与服装是否准确 → 画风与构图是否达意 → 文字及交付规格是否可验证。三视图补查高度一致、配饰左右关系和背面结构；衣服遮挡不能解释为结构被删除。

局部修正提示应指明“哪个区域、当前错误、期望结果、保留哪些内容”。例如：只修正右图天线所在侧，使其与正面母版结构对应，保留表情、配色和其余视图。
