# 测量与预算细则

> 星愿修改版（2026-10-25）：由上游同路径参考重写并校正。来源与许可见 [sources.md](sources.md)。本页是方法，不是任何引擎的性能保证。

## 测量口径

- CPU 主线程、渲染线程、GPU 和呈现存在并发与排队；先核对计时区间和等待标记。低 FPS 时 CPU/GPU 时间都短，可能是限帧、VSync、阻塞或测量口径缺失。GPU busy、线程忙时、回调间隔、屏幕呈现帧率不能互换。
- 编辑器、Development/Debug、发行版的开销不同。用可连接 profiler 的构建定位，再在接近交付的配置核验；平台不允许自选构建时注明实际环境，不要求不存在的 release 流程。
- 对尖峰保存逐帧时间线和触发事件。将冷启动与稳态分开；同样本数/时长比较 p95/p99，短样本的极端分位值不稳定。长时间负载另检查增长趋势。
- 设置长帧阈值时记录理由，例如目标预算或双倍预算；不是全平台固定用 34 ms。记录窗口和有效样本，剔除加载/后台帧必须解释，不能为改善结果删慢帧。
- 探针使用固定容量采样或聚合直方图，窗口结束再计算/输出；避免逐帧打印、大表排序、无限保存。对照关闭探针运行，估算观测开销。

## CPU、渲染提交与 GPU

Draw Call 与状态切换涉及 CPU/驱动提交成本，也可能影响 GPU 调度；减少它们可能解决 CPU 渲染线程瓶颈。不能说 CPU-bound 时减少 Draw Call 无效。GPU 瓶颈优先检查实际昂贵的 pass；透明叠加与大面积粒子会增加片元工作，数量少也可能很贵。

引擎支持时再考虑图集、共享材质、实例化、LOD、剔除和静态合并。图集不保证合批，排序、裁剪、混合、材质和渲染管线也会打断；合并过大可能损失剔除粒度、增加内存。不能把 Unity Canvas 或 SRP Batcher 机制直接套给千星。

其他引擎可查的入口（使用前核对项目版本与构建支持）：

| 引擎 | 取证入口 |
| --- | --- |
| Unity | Profiler 的 CPU/GPU/Memory/Rendering 模块；Frame Debugger 查批次与状态。Deep Profile 会增加开销；特定计数器和发行版支持需要单独确认 |
| Godot | Profiler 查脚本/物理；Visual Profiler 查渲染 CPU/GPU（受渲染器/平台支持限制）；Monitors 看对象/绘制调用/内存 |
| Unreal | `stat unit` 分辨 Game/Draw/GPU 等口径；Unreal Insights 看线程与等待；GPU Visualizer 看 pass。命令、trace channel 和可用构建依版本核实 |

RenderDoc、PIX、Tracy 等仅在目标平台支持、工具可用且任务授权允许时使用，不承诺可注入受限客户端。

## 对象池与分配

池用于已测得高频创建/回收成本的短生命周期对象；有内存与初始化代价，不把一切对象池化。

```text
prewarm(capacity): 分批创建必要对象，记录初始化峰值
acquire(): 有空闲则取用；池满按明确策略处理并计数
release(item): 取消该次使用的更新/回调/任务，重置状态，放回空闲集
teardown(): 按平台能力与生命周期释放资源和引用
```

- acquire/release 需防重复归还、过期回调及跨场景引用。重置位置、透明度、速度、寿命、计时器、事件订阅和归属；仅隐藏对象不代表停止脚本、物理或事件。
- 池容量设上限与高水位记录；关键玩法对象不能静默丢弃。允许的纯装饰降级需符合已确认视觉范围。扩容有每帧预算，避免在峰值无限增长；预热也应错峰。
- 避免热点临时表、数组、字符串格式化和重复查询；先测分配与 GC 相关性，不把一切长帧归因 GC。不以强制逐帧 GC 或盲目关闭 GC 作为默认修复。

## 少做工作与资源预算

- 事件/脏标记只在内容变化时更新；缓存需有正确失效与销毁策略。非关键 AI/HUD/装饰可降频或分帧，输入、关键判定和反馈保持约定的响应时间。
- 空间索引减少全量查询；生成/加载分帧时限制单帧工作并保留完整性与取消路径。离屏停更需明确恢复及时间推进策略。
- 纹理尺寸、三角形、Draw Call、控件、活跃粒子、setter 次数都是成本线索，不是通用阈值。按设备/分辨率/玩法负载测上限并留余量；历史数据不替代当前验收。
- 预算表只填实测或明确标为待测的值：对象总数/可见数/活跃数、每帧更新与创建数、内存或池高水位、覆盖面积与叠层、帧时间分布、首用与持续负载。
- 持续负载下降可能来自热降频，也可能是内存/对象增长、后台程序、功耗策略或场景变化。热问题需要温度/频率等证据或受控冷却对照，不能按时间长度断言。
