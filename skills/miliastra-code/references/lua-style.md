# 千星奇域 · Lua 代码风格（融合版）

> **这份文件怎么来的**：把三份外部 Lua 风格指南**融合 + 千星裁剪**而成——
> [LuaRocks](https://github.com/LuaRocks/lua-style-guide)（3 空格缩进、snake_case、LDoc、luacheck）、
> [Olivine](https://github.com/Olivine-Labs/lua-style-guide)（CC0；2 空格、单引号、busted、工厂函数）、
> [Daedalic](https://github.com/DaedalicEntertainment/lua-coding-conventions)（2 空格、camelCase、PascalCase 类、Doxygen、断言行参）。
> 三份**互相冲突**（缩进 2/3/4、引号单/双、命名 snake/camel、行宽 80/100/无）——冲突处一律由
> **「千星平台约束 + 本工程既有代码」**仲裁：外部指南只提供**我们没写过的东西**，不推翻已在跑的风格。
>
> **不做什么**：不引进沙箱里不存在的东西（`require` 第三方库、busted、luacheck、rockspec、`class()` 辅助函数、着色器级渲染）。
> 逐条取舍见 [附录 A](#附录-a三份外部指南逐条取舍)，来源与许可见 [附录 B](#附录-b来源许可与未采用清单)。

## 1. 千星专属硬规则（外部指南都没有，**优先级最高**）

| # | 规则 | 为什么 |
|---|---|---|
| 1.1 | **生命周期函数名是平台的**：`OnInit` / `OnStart` / `OnEnable` / `OnDisable` / `OnUpdate` / `OnLevelUpdate` / `OnDestroy`——只许平台调用；不要定义同名局部函数、不要手动调用它 | 运行时按固定名查找回调；覆盖/误调用会让脚本"看起来跑了其实没跑" |
| 1.2 | **`OnUpdate` 全体包 `pcall`**，异常转成**聚合故障块**（首错 / 尝试数 / 最后原因 / 交接值），同一故障只报一次 | tick 内抛错 = 静默死亡；聚合块让一次试玩就能定位（俄罗斯方块/双相/侦探杀三轮均一轮定位） |
| 1.3 | **参数校验用「显式检查 + 返回错误串 → `fail()`」**，不要用 `assert` 引爆；`assert` 只留给"绝不该发生"的开发期自检 | 运行时抛错中断整帧、信息零散；`fail()` 能把上下文一次性打全 |
| 1.4 | **沙箱禁用清单**：`io.*`、`coroutine.*`、`string.dump`、除 `os.time/date/clock/difftime` 外的 `os.*`、除 `debug.traceback` 外的 `debug.*`；**补充** `math.isnan` / `math.isinf` | Lua 5.3 + 平台裁剪；用了就是运行时 nil 调用 |
| 1.5 | **UTF-8 无 BOM**（文件前 3 字节必须 `2d 2d 20` 即 `-- `）；中文注释**可以且鼓励**（工程通篇中文） | 实测：带 BOM 会让 Lua 报 `Read text file with BOM header may cause Lua error` |
| 1.6 | **日志格式**：`[标签] 消息`（标签 = 挂载名/模块名，如 `[侦探1/board]`）；关键数值写成 `k=v`（`x=814 lv=3`） | 插件 `miliastra_log op=metrics` 直接抽 `k=数字`；标签让多脚本日志可切分 |
| 1.7 | **单条日志 ≤10000 字符**（超出**静默截断**）；长输出必须**分片**打 | 实测撞过：枚举 164 项第一片就被切掉，反向得出"没有这个键"的错误结论 |
| 1.8 | **多脚本共容器 = 黑板纪律**：跨脚本字段**归属明确、单向写**（写入者=主控），其余脚本只读；新增/改字段先改主控并登记；**禁止"扫描并清理兄弟控件"** | 实测事故：`view` 脚本"隐藏所有非自己建的控件"把 `input` 的热区与 `fx` 闪效层一起隐藏 ⇒ 点击彻底失效 |
| 1.9 | **主控若是构建产物就不要直接改**（如 `main.lua`）：改**片段**（`案子/<地图>/2.代码/main/*`）→ `node tools/build-main.mjs --map <地图>` → 再 deploy | 构建脚本带字段契约断言；直接改产物下次构建即被覆盖（★ 片段与成品**同在** `案子/<地图>/2.代码/`，旧的 `code/`+`sources/` 两个根已不存在） |
| 1.10 | **改完先自查日志再请人试玩**：`miliastra_code op=deploy`（结构校验）→ `miliastra_log op=runs` 看 `errorSample` 无首错 → 再让人点试玩 | 立规矩：连续 4 轮把已知会崩的版本带到真机，全是漏了这步；崩溃在日志里是**带行号的事实**，不用猜 |
| 1.11 | **可选功能失败要降级、不阻断**，并在日志里明说"不阻断"（例：`AddCursorEventListener` 在引擎里可能不存在 → 只警告 + 键位回退） | 一个可选能力不该让整局起不来 |
| 1.12 | **数值/常量集中文件顶部**（`local PLAYER_W = 22` 那种），正文引用常量、不裸写 | 与 `miliastra-ui` §3 同一纪律；改一处不漏九处 |

## 2. 命名

- **变量与函数 `camelCase`**（跟本工程既有代码：`playerCtrl` / `loadLevel` / `moverSnap` / `blockLogs`）。
  > 外部指南多推荐 `snake_case`（LuaRocks/Olivine）——**不采纳**：全库既有脚本都是 camelCase，改风格 = 无意义重排。
- **常量 `ALL_CAPS`**，相关常量用表分组或前缀分组（`K_ICE` / `K_MOVER` / `PHASE_FIRE`）。
- **布尔量加 `is` / `has` 前缀**（`isReady` / `hasWon` / `isMountOk`），**不要用否定名**（`isNotReady` → 双重否定难读，写 `isReady`）。
- 循环计数用 `i` / `j` / `pi`（配 `ipairs`），忽略的用 `_`（`for _, p in ipairs(L.plats) do`）。
- 名字长度随作用域：**循环内**可以用短名，**文件级**必须自解释；不用 `a`/`rbarr` 这类无意义名。
- 符号名**不要出现连字符或特殊字符**；不要用与平台保留名冲突的名字（`script` / `game` / `Enum` / `Color` / `math` / `table` / `os` / `debug`）。
- 表字段名用小写单词或 camelCase，保持**同一个表内风格一致**（本工程关卡表：`name/startPhase/spawn/exit/hint/zones/plats`）。

## 3. 缩进、空白与换行

- **缩进 4 个空格**（跟本工程既有代码）；**禁止 tab**；**LF 换行**。
  > 外部指南：LuaRocks 3 空格、Olivine/Daedalic 2 空格——都不采纳，理由是"不重排既有代码"。
- **二元运算符两侧留空格**：`px = px + ddx`、`a and b`、`x .. y`（`..` 可读性优先，仍建议留空格）。
- **逗号后一个空格**：`{ 0, 860, 340, 100, K_PLAIN }`；`{ ... }` 表内两侧各留一个空格。
- **函数名与参数括号之间不留空格**：`local function f(a)` ✅ / `function f (a)` ❌。
- **一条语句一行**；**不用分号**做语句分隔（`;` 只有在"同一行写两条赋值"这类极少数情形才勉强，别养成习惯）。
- **空行**：函数之间 1 个空行；逻辑分段用注释横幅（`-- ========== 物理 ==========`），不要靠连续空行。
- **行宽软上限 ~120 字符**（不硬卡）：超了多半说明表达式该拆成命名的子表达式（LuaRocks 的理由：行宽是复杂度的代理，治复杂度而不是治换行）。
- **不做对齐美化**：`local a = 1` 与 `local longIdentifier = 2` 不人为对齐（减少 diff 噪声）。
- **尾随逗号允许**（表、多行参数列表）——便于增删字段；**前导逗号禁止**。
- 单行块**只允许** `then return` / `then break` 或一句极简赋值：
  `if not p then return nil end` ✅ ／ 多条件 + 多语句挤一行 ❌。

## 4. 变量与作用域

- **默认 `local`**，永远。在共容器的多脚本环境里，漏写 `local` = 往黑板上乱写东西。
  - **例外**：**有意跨脚本的黑板字段**才写全局，且必须登记归属（见 §1.8）。
- **作用域尽量小**，声明贴近首次使用；**尽早返回**（校验留在函数开头，失败就 `return`），避免深层嵌套。
- 不要用多重赋值（`a, b = c, c - a` ❌），**交换**除外（`x, y = y, x` ✅）。
- `nil` / `false` 判断：能写真值判断就写（`if line then` 而不是 `if line ~= nil then`）；**只有确实要区分 `false` 与 `nil` 时**才显式比较。
- 表字段访问：**已知字段用点号**（`L.plats`），**动态键/列表用下标**（`L[levelIndex]`）。
- **`x and y or z` 做三元可以**，但 `y` 可能是 `false`/`nil` 时**别用**（会选到 `z`），那种情况写显式 `if`。
- **前置声明 + 赋值**（本工程实测需要的唯一 `f = function()` 形态）：
  当 A 需要调用**定义在其之后**的 B 时——
  ```lua
  local restartToLevel1          -- ① 先声明槽位
  local function loadLevel(i)
      -- ...
      restartToLevel1()          -- 闭包捕获的是上面那个槽位
  end
  restartToLevel1 = function()   -- ② 再赋值（用 `local function` 会新建槽位，闭包抓不到）
      -- ...
  end
  ```
  这是 Lua 词法作用域的硬规则，不是风格偏好——踩过一次（按钮回调永远是 nil）。

## 5. 函数

- **默认 `local function name(...)`**；`name = function(...)` 只在两种场合：**回调/表值**、以及上面的**前置声明回填**。
- **参数 ≤ 6 个**；更多就传一个表（字段自解释）。
- **可选参数放最后**，并给默认值：`function f(a, b, opt) opt = opt or DEFAULT`。
- **不要用布尔当"模式"参数**（`f(x, true)` 读不懂）——用字符串常量或拆成两个函数。
- **小函数优先**：一个函数只做一件事；复杂函数拆开后**让名字解释"做什么"**，答案就不必写在行内注释里。
- 表里的函数**在表外声明**（`local function attack() end` + `player.attack = attack`），别塞进表构造器里——长文件里"谁是谁的方法"会看不清。
- 匿名函数只用于"当场传进去"的回调（事件监听、`pcall` 包装）。

## 6. 表与常量

- **能一次写完就一次写完**（表构造器列字段），不要"先建空表再逐个 `t.a = 1`"（动态构建除外）。
- 表构造器里 **`key = value` 一行一个**，便于增删与 diff。
- 常量集中在顶部（§1.12）；**只读表用命名约定 + 注释标注**（本工程不引入外部 `enum()`/`readonly` 辅助库——沙箱里没有）。
- 用 `#t` 求长度只对**连续数组**可靠；表中混入 `nil` 时长度未定义——需要时自己维护计数（本工程用 `#platCtrls + 1` 这类显式追加）。

## 7. 字符串与数字

- **字符串用双引号 `"..."`**（跟既有代码；LuaRocks 亦如此）。字符串里含双引号时再用单引号，避免转义。
- 长文案**用 `..` 拼接并按行断开**（别用 `[[ ]]` 长串：缩进会一起进内容）。
- **类型转换显式**：`tostring(n)` / `tonumber(s)`；**不要**靠 `n .. ""` 这种隐式转换。
- 数字格式化：**整数用 `math.floor(x)` 后再拼**；不要对可能为浮点的值用 `%d`（引擎实测会报错）。

## 8. 控制流

- **`else` 不跟在 `return` / `break` 后面**：提前返回，减少一整层缩进。
- `if/elseif/else` 的链很长时，**把"兜底"放最后**，中间某支若"什么都不做"就写注释说明（别写空块）。
- 遍历：数组用 `ipairs`，字典用 `pairs`；需要键但不用值就用 `_`；**不要在 `pairs` 遍历中增删表**（先收集再处理）。
- 条件表达式复杂时**加括号分组**：`if (a and b) or c then`——别让读者去背优先级。
- 括号内**不留空格**：`if (a and b) then` ✅ / `if ( a and b ) then` ❌。

## 9. 错误处理与自检（千星版）

- **`pcall` 包住"平台调用可能失败"的地方**：`InstantiateClientUIControl`、控件属性写入、`ServerSignal` 发送、`Add*EventListener` 注册……
- **失败去向二选一**（明确标注）：影响能否玩的 → **`fail()` 聚合故障块**；只是可选增强 → **降级 + 日志明说"不阻断"**（§1.11）。
- **错误信息要能被日志捞到**：带上"谁 + 哪一步 + 关键值"（`"第" .. i .. "关 平台" .. pi .. " 创建失败(" .. tostring(err) .. ")"`）。
- **不静默吞错**：`pcall` 的返回值必须被使用（要么 fail、要么 log），`local ok = pcall(...)` 然后什么都不做 = 埋雷。
- **交付自查顺序**：`deploy`（结构校验 strict）→ `miliastra_log op=runs`（看 `errorSample`/首错）→ 才请人试玩。
- 静态自检工具对照：外部指南说"过 luacheck"——**本域没有 luacheck**，等价物是 **`miliastra_code op=deploy` 的内建 lualint**（缺 `end`、括号不配平、字符串未闭合、`repeat` 少 `until` 直接拒绝部署）。

## 10. 注释与文件头

- **`--` 后留一个空格**：`-- 好的注释`；注释**单独成行**（不要塞在代码行尾）。
- **不用 `--[[ ]]` 做普通注释**（只用于临时屏蔽大段代码）——`[[ ]]` 容易被误当长字符串。
- **标签注释**：`-- TODO:` 待做、`-- FIXME:` 已知问题——便于全库搜索。
- **文件头（本工程既有格式，照抄）**：
  ```lua
  -- ============================================================
  -- <模块/玩法名> v<版本>（<用途>）【<关卡/环境>】
  -- vX.Y（<日期>，<依据：谁提的/哪条日志>）：<改了什么>、<为什么>
  -- ...（逐版累加，一行一版，不要覆盖历史）
  -- 交接值（谁给的、何时、怎么读到的）：容器节点=…、模板=…、资产=…、挂载名=…
  -- 键位：…   物理：…（跳高/跳距这类可量化的数）
  -- 接口：《API 文档》§…（用到的章节）
  -- ============================================================
  ```
  版本块的价值是**排障对号**：日志里打出的版本行能与文件头对上，就知道"游戏跑的是哪一版"。

## 11. 提交前自查（逐条过）

> **先跑机械门禁**（本工作区；两道都带 `--selftest`）：
> ```powershell
> node tools/check-lua-scope.mjs                        # 作用域：漏 local、闭包抓不到前文声明（error 级）
> node tools/check-lua-style.mjs --baseline             # 风格：error 必过 + 不许比基线变差（★ 日常跑这条）
> node tools/check-lua-style.mjs                        # 想看具体是哪几行时去掉 --baseline
> ```
> **error 级红了不许 deploy**；warn 走**基线**约束——"新代码不许让任何一条规则超过基线"，
> 存量不强求一次清完（顺手清了一批就 `--update-baseline` 把基线往好的方向推）。
> 基线文件是 `tools/lua-style-baseline.json`（只记数字，针对默认目标的 6 个活文件）。
> 下面这些**机器判不了**，只能人/AI 读规范——所以清单还得逐条过。

- [ ] 文件**前 3 字节是 `2d 2d 20`**（无 BOM），UTF-8，LF
- [ ] 缩进 4 空格、无 tab；运算符/逗号两侧空格；无分号
- [ ] 变量函数 camelCase、常量 ALL_CAPS、布尔带 `is/has`
- [ ] **默认 `local`**；写全局的只有登记过的黑板字段
- [ ] `OnUpdate` 包了 `pcall`，故障聚合块在；`pcall` 的返回值都被用了
- [ ] 关键日志是 `[标签] 消息` 且含 `k=v`；长输出分片；单条 <10000 字符
- [ ] 平台调用都包了 `pcall`；可选功能是"降级不阻断"
- [ ] 没碰兄弟脚本的字段/控件（黑板单向写；无"清理兄弟"逻辑）
- [ ] 文件头版本块已更新（日期 + 依据 + 改动）
- [ ] `deploy` 结构校验通过，且 `log op=runs` 没有首错
