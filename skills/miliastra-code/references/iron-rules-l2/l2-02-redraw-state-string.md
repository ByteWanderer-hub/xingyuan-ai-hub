# L2-02 重画判据用**状态串**，不要只用 `fx` 单值

> 归属：`miliastra-code` 语义铁律（默认不查）｜从 `iron-rules-lua.md` 拆出（内容未改）

- **真实事故**：新一局 `fx` 从 0 重新数，很容易和上一局最后一个 `fx` 撞上 ⇒ 判定"没变化" ⇒ **HUD/格子整屏停在上局画面**（"黑条一直挂着、时间是上一局的"）。
- **判据**：`if rawState ~= lastRaw then render() end`；心跳每秒写一次状态当"至少每秒重画"的兜底；**任何想触发重画的动作必须顶 `fx`，诊断/心跳绝不能顶 fx**。
- **过查方法**：grep `fx` 的比较点，确认同时有状态串比较；grep 心跳分支里有没有 `bumpOnly()`。
