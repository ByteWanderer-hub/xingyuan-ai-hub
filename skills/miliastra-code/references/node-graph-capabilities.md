# 节点图能力的读取与使用方式（`miliastra_map` 的 `.gil` 六件套 + 挂载关系）

> 沉淀。**用途**：拿到一张地图，回答"它有哪些节点图、谁身上挂着、每张图什么时候跑、跑起来会做什么"。
> ⚠️ **全部是结构事实**（`.gil` 里的字段），**不是语义结论** —— 工具只报数字，判断留给作者（铁律）。
> ⚠️ **改了插件工具就要重启 `dsh web`**：Host 侧的回执字段/新 op 只在重启后对 AI 可见（面板另需 F5）。
> 实测方法：读 `.gil` → 与编辑器面板逐条对照 → 只把**对得上**的口径写成"已确证"。

## 0. 先选 op：我要问什么

| 我想知道 | op | 关键字段 | 别用它答 |
|---|---|---|---|
| 这张图里**都有些什么**（区级） | **`regions`** | `regions[]`（`field/label/bytes/itemCount/sampleNames`）+ `counts` | 不是节点级；未确证的区 `label:null`（**不编名字**） |
| 有哪些节点图 / 实体 / 元件 / 声明 | `nodes`（`kind:"all"`） | `graphs/entities/components/declarations/mounts` | `summaryOnly` 默认**只给计数** |
| 某张图的**能力画像** | `anatomy` | 每图 `byType/bySide/triggers/refs/keywords/owners` + `anatomyNote` | 不是逐节点连线 |
| 某张图的**逐节点 + 引脚 + 连线** | `nodes` + `graph:"<图名子串>"` | `nodes[图名][]`（index/doc/x,y/pins/outEdges）+ `edges[图名][]` | 图名要**子串能命中**（`异常聚合` ✓，带全名也行） |
| 哪张图**挂在谁身上** | `anatomy` / `nodes` | 每条图 `owners[]`（`via:"mount"` 已确证 / `"ref"` 未确证） | **不读不出来**——能读（见 §2） |
| 脚本映射 / 客户端控件模板 | `script` / `clientui` | `mappings[].embedded.vs live`（`match`）/ 无父节点的模板 | `clientui` 只列**能被脚本创建**的模板 |
| 节点名/端口 | `nodedb` | 558 条官方词典（`q`/`system`/`domain`/`nodeId`） | 词典 id ≠ `.gil` 里的声明号 |

★ **这份表的用处**：作者问「实体保守估计 50 个、场景静态更多」时，答案是 **"实体表 12 条" ≠ "图里只有 12 个东西"** ——
**场景静态在 `#27`、摆放实例在 `#8`**。报数时**必须把四个计数一起说**（实体 / 元件 / 摆放实例 / 场景物件），否则会被读成"东西很少"。

## 2. 挂载关系：**能读**（这是最重要的一条，附我上一轮的错法）

**已确证判据**（与编辑器「节点图挂载对象」面板**逐条对上**）：

```
实体记录  #5[i] . #6 . #13 . #1[] . #1 { #1=序号, #2=图id, #501=图类型号(实测 20000) }
元件记录  #4[i] . #7 . #13 . #1[] . #1 { … 同上 … }        （元件把 #6 换成 #7，形状相同）
```

- 回执里标 `via:"mount"` = **已确证**；实测覆盖：恐怖-V3 **34/57** 张图有这种主，侦探1 **1/19**（其余是技能图/状态图）。
- **另一类形状**（`#7.#27.#2.#6.#2`、`#7.#38.#501.#504.#2` …）也指向某张图 —— 实测那 21 张正是**客户端布尔过滤器图** ——
  但口径**未确证** ⇒ 回执标 `via:"ref"`，**不冒充挂载**。
- ⚠️ **盲区必须一起说**：**技能图 / 状态图**挂在**技能、职业、状态**等**别的区** ⇒ 实体/元件区里查不到它们的挂载主。
  没找到时只能说「**这两个区里**没找到」，**不许说"这张图没挂载"**。
- ⚠️ **上一轮我错在哪**（留作反面教材）：
  ① 按**名字**匹配（57 个图名只有 1 个与实体名全等）；② 按**裸数值**命中（号段重叠，同段随机号也会撞）。
  两条都**不是证据** ⇒ 必须**按结构路径**取。
- 名字要从**同一条记录**里读（`#5[槽1].#11` / `#6[槽1].#11`），而且有些名字是**"套一层"**的（`#11.#1` 才是文本）——
  直接解 `#11` 的字节会把 tag 字节当文本 ⇒ 名字丢掉 ⇒ 面板显示成「(无名)」（已修：`deepTxtOf()` 深取）。

## 3. 「挂在 XX 上的图能做到什么」= 入口事件 + 关键动作（`op=nodes` 每条图自带）

回执里每条 `graphs[]` 都给（**从已读进来的节点算，不再读第二遍 `.gil`**）：

| 字段 | 含义 | 口径警告 |
|---|---|---|
| `owners[]` | 挂载主（`kind/name/id/via`） | `via:"ref"` 未确证；空 = 这两个区里没找到 |
| `entryEvents[]` | **事件类节点名**（`定时器触发时` / `进入碰撞触发器时` / `界面控件组触发时`…） | 同一事件挂多个会重复出现（**不去重**——那是真的挂了两次） |
| `actions[]` | **执行类节点名去重保序**（前 8 个） | ⚠️ **"调用了哪些动作节点"，不是"它想干什么"** |
| `actionTotal` / `actionUnknown` | 执行节点总数 / 名字没查到的个数 | 词典覆盖不到时名字给不出，但**引脚与连线照样有** |
| `byType` / `bySide` / `keywords` / `refs` | 类型直方图 / 端 / 图名加权关键词 / 「图 → 引用了谁」 | `refs` 方向**不是**"谁拥有这张图" |

**用法示例**（真数据）：`关卡实体` → `关卡_异常聚合`，63 节点 / 104 连线，入口 `定时器触发时 / 全局计时器触发时`，
关键动作 `启动定时器 · 创建元件 · 设置预设状态 · 设置自定义变量` ⇒ 可读作"**定时轮询 → 取变量 → 算 → 分支 → 写变量/建元件/重启定时器**"的逻辑。
**这么读要说清是推断**；要更强证据就去 `graph:"异常聚合"` 拿 `pins` 与 `edges`，追"哪个值喂到哪个引脚"。

## 4. 与知识库配合（`miliastra_kb`）

- `{"op":"qa"}` 看目录；`{"op":"qa","q":"镜头 不生效"}`（多词 = AND）；`{"op":"qa","id":"..."}` 取单条。
- 覆盖：官方自查 9 条 / 官方调试 / **米游社问答楼高频坑**（背包事件只在道具节点图上生效、角色一死自己的图就没了、
  开局唤起界面要延迟约 2s、运动器带动的物体之间触发不了碰撞、血条属于铭牌、结算显示"完成"要查关卡设置+逃跑合法性…）。
- `{"op":"node","q":"设置自定义变量"}` 先查**离线词典**（带端口），查不到才走在线兜底（会披露 `network:true` / `sentTo`）。
- ⚠️ **离线 op 永不联网**；在线失败**不许说"知识库里没有"**（要说"没取到"）。

## 5. 纪律与坑（读 `.gil` 这一类活儿）

1. **静默截断是头号坑**：读取层默认上限（元件曾默认 **40**）会把 71 条砍成 40 条 ⇒ 回执必须带 `truncated{}`；
   拿到的计数要与"区里实际条目数"对账（**回执数 == 实际数，除非显式说截断**）。
2. **计数不许是 `undefined`**：早退路径（没有该区）也要给 `0`，否则回执看着像坏了。
3. **口径要写进回执**（`anatomyNote` / `mountSummary.note` / `regions.note`）：已确证 vs 未确证 vs 盲区，
   让下一个人（或下一个我）不必重新踩一遍。
4. **别把 `.gil` 当实时**：它是**存盘那一刻的快照**；"谁在跑"要看 `miliastra_playtest` / `output_log.txt`，
   `miliastra_log` 读的是**上一局**（一局结束才落盘）。
5. **换图 = 换号**：关卡 id、图 id、实体 id、声明号**都随图变**，任何写死的号换图即废 ⇒ 每次现读（`op=clientui` / `handover`）。
6. **改完工具要重启 `dsh web`**（Host 侧），面板改动 F5；**别用"我以为生效了"当验证** ——
   用真工具调一次（新 op 会以 `未知 op` 的形式暴露旧 Host）：
   ```
   miliastra_map {"op":"regions","level":"1073741829","summaryOnly":true}
   ```
7. **落档**：地图相关的报告按工作区 §1.5 进 `案子/<地图>/1.策划案/`（如
   `案子/恐怖-V3/1.策划案/节点图报告/挂载表-1073741829.md`），**不许留在 `docs/` 或工作根目录**。
