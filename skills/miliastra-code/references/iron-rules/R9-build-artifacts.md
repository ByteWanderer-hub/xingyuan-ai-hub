# R9 构建产物不许直接改

> 归属：`miliastra-code` 机械可查铁律｜从 `iron-rules-lua.md` 拆出（内容未改）


- **判据**：存在 `tools/build-*.mjs` + **构建源片段目录** ⇒ 那个 `.lua` 是**拼出来的产物**。
  ★ 片段目录现在就在 `案子/<地图>/2.代码/` **里面**（成品与源同目录）：侦探1 = `main/`；双相 = `{main,input,view,levels,mechanics,select}/`；
  夏日祭法师 = 同层的 `主脚本/主控/特效/元素.lua`（产物是 `夏日祭*.lua` / `夏祭*.lua`）。
 （之前是 `sources/<玩法>/` 与成品 `code/<玩法>/` **两个根**，**都已不存在**。）
- **正确做法**：改**片段** → `node tools/build-main.mjs --map <地图>`（带**字段契约断言**：断则拒绝落盘）。
  ⚠️ 每个构建器**只服务它那张图**，给别的 `--map` 会明确报错退出。
- **真实事故**：直接改产物，下次构建**被覆盖**（本轮整改里 `main.lua` 的头部就是改 `01_head.lua` 再重建的）。
