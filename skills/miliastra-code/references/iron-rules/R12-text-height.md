# R12 文本控件的**矩形高度**必须容得下字号行高（`h ≥ fontSize × 1.4`）

> 归属：`miliastra-code` 机械可查铁律｜从 `iron-rules-lua.md` 拆出（内容未改）


- **真实事故（两次真机白跑）**：设置菜单顶部的「第 X 关 · 关卡名」在真机上**整条空白**——
  `52` 号放进 **64** 高、`64` 号放进 **80** 高，两个版本都不显示；同面板里 28 号的按钮文字一直正常，
  把 `52` 号放进 **90** 高（另一处大标题）也一直正常。
- **机制**：`ClientUITextBoxControl` 的 `sizeDeltaY` 容不下字号行高（CJK 字体 ≈ **1.4 × fontSize**）时，
  该控件**一个像素都不画** —— 不裁切、不缩小、不报错，`visible` 仍为 `true`、`text` 也确实设上了。
- **为什么日志/模拟器都抓不到**：`.gia` 里那行"文字设上了"照样打印；`miliastra_sim` **不模拟这个截断**
  （同一份代码它画得出来）⇒ 只有**真机截图 + 量像素**能看出来。
- **判据（量像素）**：底图区域均值精确等于底图 token；文字区若与底图**一模一样**（零像素差、无深色描边团）
  ⇒ 是"什么都没画"；若是**另一块颜色** ⇒ 才是"被压住"。
- **规矩**：定字号时同时按 `fontSize × 1.4 + 余量` 给高度（64 号 ≥ 96，常用 120）；矩形加高**不会挪动字形**
  （文字垂直居中）⇒ 零视觉代价。
- **审查动作**：`node tools/check-ui-contract.mjs` 的第 ④ 条（自动配对 `add(...  "txt", x,y,w,h)` 与
  `setFont` / `.c.fontSize`，`makeBtn` 的文字按 28 号算）。
