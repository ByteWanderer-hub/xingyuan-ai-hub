## 地图约定

- 本项目美术/UI 默认结合 UI UX Pro Max；厨房、冰箱、冰柜、蒸笼、锅、蒸格、简单几何为当前地图方向。设计方法不替代千星 API 和原生控件约束。
- 角色映射：恶魔→待蒸面团，人类→空碗，小孩→冰淇淋。关卡只生成实际存在的角色，不为展示新增角色改变机制；独立美术测试关可以展示全部类型。
- 门与背景鲜明对比，保留可辨认门板、轴点/把手及开关关系；容器收紧到门及必要活动/点击范围。
- 气体静态本体只用单色填满合法房间内域，不加高光、云团或独立标识。完整素材接入后不保留占位字符；角色/器具允许轮廓、阴影和高光，不能把气体禁高光误用到所有美术。
- 对外沿用 `dNN` 房间、`mNN` 门序号或已确认脚本支持的 `mNN-NN` 两端命名，不能混淆两种编号含义；`dNN_gasNN` 气体分片、`aNN` 角色、`uNN` 器具、`kNN` 口袋。门内部“可动门”“光标检测区域”等原生绑定名保留。
- 核对当前脚本的单项查找/遍历能力；多个同名房间不保证都被处理。现有脚本需要适配全分片更新，GIA 不自动完成接入。
- 静态展示覆盖 NONE/STEAM/MIST、三角色、ICEBOX/STOVE、门开关、SUCK_HOST/PARTITION_HOST；DIAGONAL 为实验样式，不因放入测试关就升级为已支持玩法。
- 波动、碎片转移、吸放、角色状态及胜负需要脚本。原作参考 https://patrickgh3.itch.io/divine-doors 的页面已读取，交互浏览器超时，尚未核实动画；不得声称复刻完成。
