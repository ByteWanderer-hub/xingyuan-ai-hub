# 蛋仔工坊 Lua 开发

在 [接口索引](references/api.md) 搜中文动作或英文名。CLASS 用来辨认参数类型，ENUM 用来核对可选值。函数按 LuaAPI、GlobalAPI、GameAPI 和单位 API 分区。同名动作先看接收对象，再打开条目核对参数顺序、类型、返回值和示例调用写法。

例如，给巡逻路径增加路点时检索 `GameAPI.add_pathpoint`。参数依次是路径 ID、插入索引、路点 ID。路径和路点取当前地图的数据。给技能进入冷却则查 `Ability.enter_cd`，并核对示例中技能实例的调用方式。

首次建图从 [快速入门](https://ugc.163.com/manual/pc_md/lua/lua_quickstart.html) 开始。通过 PC 编辑器生成 Lua 工程，在 VS Code 打开该工程，连接两端的蛋仔开发助手。场景对象和 UI 节点的 ID 可从插件数据区复制。改动后先看文件同步记录，再运行地图，依据控制台的编译错误或运行轨迹定位脚本行。[开发助手](https://ugc.163.com/manual/pc_md/lua/lua_eggitor.html)

遇到本地工程缺少手册函数时，先用插件导出当前 API，再对照 [接口结构](https://ugc.163.com/manual/pc_md/lua/lua_api_structure.html) 和手册侧栏的更新日志。交付时区分文档核对与地图实际运行结果。

## 从需求到试玩

按任务查 [开发手册导航](references/workshop.md)。开工先写清玩家输入、状态变化、可见反馈、失败和重试条件。把它们落到同一张最小测试地图，再扩展美术和内容。

| 任务 | 蛋仔实现入口 | 最小验收 |
|---|---|---|
| 关卡与场景 | 关卡管理、组件预设、地形、碰撞预览和规则设置。用出生点、一个机关、一个终点先走通主路径。 | 从出生到胜负结算走一遍，失败重生后机关恢复。 |
| 蛋码与 Lua | 可视事件链先查触发器和五类积木；脚本查运行环境、事件注册和对象类型。为每个状态指定一个写入方。 | 同一事件记录触发对象、次数与前后状态，重开后无重复响应。 |
| UI 与交互 | 从界面编辑器选控件，区分屏幕界面与场景界面。运行时 ID 取目标地图导出数据。 | 打开、操作、关闭、重开；不同宽高比下检查遮挡、触控与状态刷新。 |
| 动画与特效 | 固定机关运动查运动器，角色姿态查骨骼与动作编辑器，过场查剧情动画，光束与法阵查 VFX 实例。 | 按预警、命中、结束三处截帧，核对判定时刻；中断后检查残留。 |
| AI、技能与战斗 | 用行为树组织感知与动作，用技能和效果编辑器配置释放条件和结果。 | 覆盖目标进入、离开、死亡、冷却中再次输入。 |
| 物品、存档与多人 | 区分局内状态、玩家持久数据、成就和排行榜；先验证一条获得与保存路径。 | 两位玩家分别操作，核对归属；重复领取与重新进入后核对余额。 |
| 素材与共建 | 查资源包、模型上传、组件预设和 PC 共建说明。记录依赖的预设与实际地图版本。 | 在目标草稿实例化一次，核对材质、碰撞、引用和协作后版本。 |
| 性能与交付 | 固定设备、地图和视角，逐级增加同屏对象、活跃逻辑或特效，单独改变一项。地图发布与更新走工坊入口。 | 记录基线和复测条件；验证目标设备、重新进入及发布版本。 |

## 官方编辑器联调

Windows 默认工具为 `~/.eggitor/cli/editor-cli.exe`。启动编辑器并开启 editor-cli 后，用 `editor-instances list`、`status --json` 和 `map current` 核对实例、地图及是否处于试玩。多实例用 `--editor-instance` 指定目标。下面是该程序的子命令。[官方 CLI 使用指引](https://ugc.163.com/manual/pc_md/editor_cli.html)

1. 绑定目标地图的代码目录前先看 `code init -h`。用 `code diff` 比对本地、编辑器与基线，再按变更方向选择拉取或推送。覆盖已有改动前保留副本。
2. 用 `code validate` 核对脚本。获得写图授权并确认目标后才执行 `code push`；再次比较差异。
3. 用 `play start` 进入试玩，用 `status --json` 核对状态。按验收动作观察游戏截图与事件记录；用 `log trace`、`log latest` 定位错误，结束用 `play stop`。编辑态、试玩服务端与客户端调用上下文分别查手册。
4. 交付记录地图版本、修改对象、同步结果、实际试玩结果及设备。截图证明画面，行为验证还需输入与状态结果。公开发布另行核对目标与授权。

千星 GIA/GIL、节点图注入、基础图片 ID 和 Lua 宿主绑定均为平台专有。蛋仔资产与 UI 使用工坊资源和地图导出 ID；可复用的部分是关卡节奏、动效设计、性能对照实验和验收方法。
